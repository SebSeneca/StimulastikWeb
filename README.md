# StimulastikWeb
This is a simple SPA project for the small business "Stimulastik v. Karina Jensen".

The project is build using Vue 3 and Typescript. It is a very light weight program that provides the most important information regarding the business, in a stylish and accecable manor. 

To run the project, clone the code to a machine with Node.js installed, navigate to the source folder and run "npm run dev".
